# Sample files

Place your own PDFs here while you try DocShift locally.

This folder is not required to run the app. Automated tests create small synthetic PDFs instead of storing personal documents.

Suggested checks:

1. A simple text PDF (letters, reports).
2. A PDF that contains a table.
3. A PDF that contains a photo or logo.
4. A scanned PDF if you have installed Tesseract.
